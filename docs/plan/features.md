# Feature List

The 15 features selected for the first release. IDs are referenced from the implementation plan, the manual test guide and issues.

## Menu bar

| ID | Feature | Description |
| --- | --- | --- |
| M01 | Hide, always-hide and arrange icons | Keep only frequently used items visible; the layout survives a relaunch. |
| M02 | Reveal hidden icons quickly | Reveal by hover, click or hotkey, then hide again automatically after use. |
| M03 | Secondary menu bar | Operate hidden icons from a bar below the notch or near the pointer. |
| M04 | Auto-arrange by notch and screen width | Hide items automatically when space runs out and swap visible and hidden items temporarily to reach what you need. |
| M05 | Icon groups and spacers | Bundle related icons into groups and tidy the bar with spacing and separators. |

## Notch panel

| ID | Feature | Description |
| --- | --- | --- |
| N01 | Island-style panel around the notch | Open music, tasks and status from the notch or a floating island. |
| N02 | Widget selection, order and layout | Keep only the widgets you need on the top shelf and arrange them together. |
| N03 | Multiple live activities at once | Show a primary activity and a secondary one together to follow timers, music and task state. |
| N04 | Hover, drag and swipe behaviour | Adjust open and close delays, the hover area and page-navigation gestures. |
| N05 | Panel size, position, color and animation | Tune the notch or island appearance and response speed. |
| N06 | Full-screen and Mission Control rules | Show or hide the panel automatically depending on the situation. |
| N07 | Hide from screen sharing and screenshots | Keep the panel out of meetings and captured images. |
| N08 | Coordinate the menu bar and the notch panel | Keep menu bar icons and the expanded panel from covering each other. |

## Window management

| ID | Feature | Description |
| --- | --- | --- |
| W01 | App and window switcher | Per-app windows, live thumbnails, search, and minimized and full-screen windows. |
| W02 | Switcher display and per-app rules | Simple mode, grouping or excluding apps, and choosing the target display. |
